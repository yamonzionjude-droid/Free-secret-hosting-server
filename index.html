📋 How players connect

Java: copy the server address. If a non-default port is used, copy address:port.
Bedrock: enter the address as IP/hostname and the port separately.

The address and port fields below are customizable display/configuration values. A website cannot create a real public IP, open a network port, or make a Minecraft server run by itself. The actual IP/port must come from the server machine or hosting provider.

🚀 V2 backend status

V2 is fully functional as a mobile control panel: server data, addresses, ports, and status are saved in your browser and the copy buttons work. The Start button does not falsely claim to launch a remote Minecraft server.

To make Start/Stop actually control a Minecraft server, V3 needs a backend/hosting API connected to this panel.
